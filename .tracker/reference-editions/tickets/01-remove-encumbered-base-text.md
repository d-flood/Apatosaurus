# 01 — Remove the encumbered NA28 base text

## What to build

Delete the one file in the bundled IGNTP corpus that this repository is not permitted to redistribute, and regenerate the catalog so it no longer offers it.

`app/static/igntp/Romans_Greek_transcriptions/NT_GRC_basetext_Rom.xml` is the NA28 text. Its own TEI header states: *"It is also prohibited to distribute this text via the internet without written permission of the German Bible Society."* The file is git-tracked and served from GitHub Pages today.

It is also the only encumbered file in the corpus. A survey of every `<availability>` statement across all 167 files found 157 CC BY 4.0, 9 CC BY-NC-SA, and this one. Do not touch the other 166.

Demo: the IGNTP import panel no longer lists an NA28 entry, and the file is gone from the build output.

## Where to start

- The file: `app/static/igntp/Romans_Greek_transcriptions/NT_GRC_basetext_Rom.xml`.
- The generated catalog it appears in: `app/src/lib/igntp/catalog.generated.json` (entry near line 1278).
- The generator: `app/scripts/generate-igntp-catalog.ts`, which calls `buildIgntpCatalog` in `app/src/lib/server/igntp-catalog.ts` and rewrites the JSON. There is no package script for it; run it with `tsx`.
- Catalog consumers, for confirming nothing else references the entry: `app/src/lib/igntp/catalog.ts`, `app/src/routes/transcription/(library)/igntp/+page.svelte`.

## Contract

- The file is removed from the working tree **and** from git tracking.
- `catalog.generated.json` is regenerated by running the generator, not hand-edited. Its `generatedAt` timestamp will change; that is expected.
- The resulting catalog has 166 entries in the `Romans_Greek_transcriptions` group.
- No other IGNTP file is deleted, moved, or modified.

## Out of scope

- The other 166 IGNTP files. The 9 CC BY-NC-SA ones are fine to keep.
- Attribution surfacing for CC BY files. That obligation is real but belongs to the reference-edition work, not here.
- Any change to the IGNTP import flow, its panel, its duplicate-key helper, or the required-metadata check that currently makes this entry unimportable. The entry is going away; do not "fix" it on the way out.
- Adding Robinson-Pierpont. That is ticket 04.

## Acceptance criteria

- [ ] `app/static/igntp/Romans_Greek_transcriptions/NT_GRC_basetext_Rom.xml` does not exist and is not tracked by git.
- [ ] `catalog.generated.json` contains no entry whose `fileName` contains `basetext`, and no entry whose title mentions Nestle-Aland or Deutsche Bibelgesellschaft.
- [ ] The `Romans_Greek_transcriptions` group has exactly 166 entries.
- [ ] No string `Deutsche Bibelgesellschaft` remains anywhere under `app/`.
- [ ] Existing suites still pass.

Commands:

```sh
# from repo root
git rm app/static/igntp/Romans_Greek_transcriptions/NT_GRC_basetext_Rom.xml
cd app && pnpm exec tsx scripts/generate-igntp-catalog.ts

# checks
grep -ri "basetext\|Deutsche Bibelgesellschaft" app/static app/src/lib/igntp   # expect no matches
python3 -c "import json;c=json.load(open('app/src/lib/igntp/catalog.generated.json'));print(sum(len(g['entries']) for g in c['groups']))"   # expect 166

cd app && pnpm run check && pnpm run test:unit -- --run
```

Success = the greps return nothing, the count prints 166, and both commands exit 0.
