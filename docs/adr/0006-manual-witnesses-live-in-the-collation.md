# Manual witnesses and new transcriptions live in the collation, not a separate finished document

A collation stays the one document a scholar edits from first alignment to finished apparatus; manual witnesses, later transcriptions, and every hand edit are preserved through alignment changes by a single mechanism inside it.

- Adding a 28th transcription to a finished collation must keep earlier alignment and reading work, so that preservation has to exist in the collation regardless.
- A manual witness added after collation and a newly transcribed witness are the same problem: existing work, an alignment change, keep what can be kept reliably, and surface the rest loudly.
- Rejected: a separate finished document refreshed from the collation by per-unit merge, because it would build the same preservation a second time.
- Rejected: only adding manual witnesses, because it leaves legacy import and full editing unsolved.
